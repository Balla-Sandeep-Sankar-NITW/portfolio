
# 💻 Developer Portfolio SPA

A fast, responsive, and data-driven single-page portfolio website designed to showcase software projects, professional experience, and contact channels without any framework overhead or build steps.

## ✨ Features

* **🌓 Dark & Light Theme:** Smooth theme switcher utilizing CSS custom properties and design tokens.
* **⚡ Data-Driven Architecture:** Dynamically renders home sections, projects, timeline experience, and contact info from a single `data.js` configuration file.
* **🖼️ Built-in SVG Previews & Lightbox:** Custom SVG fallback illustrations for projects and interactive zoomable screenshot viewports.
* **📱 Fully Responsive Layout:** Mobile-friendly design with sticky blur navigation, custom icons, and fluid grid layouts.
* **🚀 Zero Build Step:** Pure Vanilla JS (ES6+), HTML5, and modern CSS (Grid & Flexbox)—runs natively in any browser.

## 🛠️ Tech Stack

* **Core:** HTML5, CSS3 (Variables, Grid, Flexbox), Vanilla JavaScript (ES6+)
* **Typography:** Inter & Caveat (Google Fonts)
* **Icons & Art:** Custom inline SVG icons and vector project visualisations
